Les huit défauts à retrouver

Le grand livre contient volontairement huit catégories de défauts. Vous devez les retrouver, pas les croire sur parole :

  1. Montants en texte : Débit et Crédit sont écrits 12 500,00 (espace de milliers, virgule décimale).
  2. Formats de date mélangés : 27 lignes en 15/01/2026 et 2 lignes en 2026-01-18 (pièce AC-2026-011).
  3. Casse incohérente : vente client alpha, ACHAT MATIERES PREMIERES, VENTE CLIENT gamma…
  4. Espaces doubles dans « Reglement client  ALPHA » et « loyer  avril ».
  5. Doublon exact : AC-2026-019, compte 606100, 1 450,00 au débit, deux fois.
  6. Pièce déséquilibrée : VE-2026-007, 4 400,00 au débit et 4 000,00 au crédit.
  7. Ligne sans montant : BQ-2026-014, ni débit ni crédit.
  8. Comptes absents du plan : 627000 et 281000.

État initial, fichier brut, 29 lignes : total Débit 107 735,50 ; total Crédit 105 885,50 ; écart 1 850,00. Cet écart se décompose en 1 450,00 (le doublon) et 400,00 (la pièce déséquilibrée).

Exemple 1 — importer et fiabiliser les types

Énoncé

Le service comptable vous transmet un export CSV du grand livre 2026. Chargez-le dans Excel de façon à calculer des totaux justes, sans toucher au fichier reçu.

Solution, dans Excel

  1. Excel → Données → Obtenir des données → À partir d’un fichier → À partir d’un fichier Texte/CSV.
  2. Sélectionner grand_livre_2026_brut.csv.
  3. Dans l’aperçu, vérifier : origine 65001: Unicode (UTF-8) ; délimiteur Virgule ; détection des types → Ne pas détecter les types de données. On posera les types nous-mêmes, en français.
  4. Cliquer Transformer les données. La requête s’appelle souvent grand_livre_2026_brut, avec les étapes Source et En-têtes promus. Si les en-têtes manquent : Accueil → Utiliser la première ligne pour les en-têtes.
  5. Renommer la requête GrandLivre (volet de droite, champ Nom).
  6. Onglet Affichage : cocher Qualité, Distribution et Profil de colonne, puis profiler l’ensemble du jeu de données.
  7. Colonne Debit : Accueil → Type de données → Utiliser les paramètres régionaux… → Nombre décimal, Français (France). Les 12 500,00 s’alignent à droite ; les vides deviennent null.
  8. Recommencer pour Credit.
  9. Colonnes Compte, Journal, Piece, Libelle en Texte. Un compte n’est pas un nombre : 401000 ne s’additionne pas, et le texte protège les zéros de tête.
  10. Laisser Date en Texte pour l’instant : deux formats cohabitent, une conversion naïve produirait des erreurs (exemple 2).
  11. Clic droit sur GrandLivre → Dupliquer, renommer Controle_Totaux.
  12. Dans cette copie : colonne Debit → Transformer → Statistiques → Somme. Lire, puis supprimer l’étape. Idem Crédit. Puis Compter les lignes, lire, supprimer l’étape.
  13. Clic droit sur Controle_Totaux → Fermer et charger dans… → Créer uniquement une connexion. Cette requête ne doit pas polluer le classeur.
  14. Accueil → Fermer et charger pour GrandLivre (tableau Excel).

Debit et Credit portent l’icône 1,2 (nombre décimal). Compte porte ABC. Debit a 1 vide (BQ-2026-014), Credit en a 12.

Si le total s’affiche 107735.5, ce n’est qu’un format. Si vous obtenez 1 077 355 ou une colonne pleine d’Error, l’étape 7 a été faite sans paramètres régionaux : supprimez Type modifié et recommencez.

Rappel Excel : tant que l’éditeur est ouvert, le classeur est inutilisable. On charge, on lit les totaux, on revient dans l’éditeur si besoin.

Exemple 2 — dates, libellés, doublon

Énoncé

Le grand livre doit devenir exploitable : une vraie colonne Date, des libellés homogènes, plus de ligne saisie deux fois. Chiffrer l’effet du doublon sur le total débit.

Dates mélangées

  1. Requête GrandLivre.
  2. Ajouter une colonne → Colonne personnalisée, nom DateReelle, formule :
if Text.Contains([Date], "/") then Date.FromText([Date], [Format="dd/MM/yyyy", Culture="fr-FR"]) else Date.FromText([Date], [Format="yyyy-MM-dd", Culture="fr-FR"])

27 lignes sont au format français, 2 lignes (AC-2026-011) au format ISO. Une seule convention laisserait des Error sur l’un des deux groupes.

  1. Type de DateReelle → Date. Qualité : 100 % Valide, 0 % Erreur.
  2. Supprimer l’ancienne colonne Date, renommer DateReelle en Date, la déplacer Vers le début.

Libellés

  1. Colonne Libelle → Transformer → Format → Supprimer les espaces (début et fin).
  2. Les doubles espaces internes restent. Accueil → Remplacer les valeurs : deux espaces → un espace. Renommer l’étape Espaces doubles réduits.
  3. Libelle → Format → Mettre en majuscule chaque mot.

Doublon

  1. Dupliquer GrandLivre → Controle_Doublons.
  2. Regrouper par (Avancé) : Piece, Compte, Libelle, Debit. Nouvelle colonne NbLignes = Compter les lignes.
  3. Filtrer NbLignes > 1. Une seule ligne doit rester : le doublon.
  4. Charger Controle_Doublons en connexion seule.
  5. Sur GrandLivre : cliquer dans une cellule (aucune colonne sélectionnée) → Accueil → Supprimer les lignes → Supprimer les doublons. Renommer l’étape Doublon AC-2026-019 supprimé.
Si une colonne est sélectionnée, la suppression ne compare que cette colonne. Désélectionnez d’abord.

L’écart résiduel de 400,00 n’est pas un défaut de nettoyage : c’est VE-2026-007, réellement déséquilibrée. Une anomalie comptable se signale, elle ne se corrige pas en silence dans l’outil de préparation.

Exemple 3 — confronter au plan comptable

Énoncé

Vérifier que tous les comptes mouvementés existent dans le plan, et produire la liste des écritures à compte inconnu.

Solution

  1. Accueil → Nouvelle source → Texte/CSV → plan_comptable.csv. UTF-8, virgule, ne pas détecter les types. Nommer la requête PlanComptable.
  2. Compte en Texte des deux côtés. Sinon la fusion échoue silencieusement (que des null).
  3. Renommer Libelle de PlanComptable en LibellePlan, pour éviter Libelle et Libelle.1.
  4. GrandLivre → Fusionner des requêtes (pas « comme nouvelles »). Clé : Compte des deux tables. Jointure externe gauche.
  5. Déplier la colonne Table : cocher uniquement LibellePlan et Classe, sans préfixe.
  6. Filtrer LibellePlan = (null) : ce sont les comptes inconnus. Lire, puis supprimer ce filtre sur GrandLivre.
  7. Dupliquer GrandLivre → ComptesHorsPlan, et y refaire uniquement le filtre null. Connexion seule, ou une petite feuille dédiée.
